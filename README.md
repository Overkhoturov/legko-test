# Замер скорости интернета

Консольный скрипт на Node.js: делает 10 последовательных запросов к указанному адресу, дожидаясь полного ответа на каждый, и печатает среднее время запроса, общий объём и скорость скачивания.

Зависимостей нет, нужен **Node.js 18+** (используется встроенный `fetch`).

## Запуск

```bash
node speedtest.js <url>
# или
npm start -- <url>
```

Пример (любой тяжёлый файл по http/https):

```bash
node speedtest.js https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
```

Пример вывода:

```
Адрес: https://example.com/big.jpg
Запросов: 10

# 1: 8.12 МБ за 1450 мс (44.80 Мбит/с)
...

--- Итого ---
Среднее время запроса: 1380 мс
Скачано всего: 81.20 МБ (81200000 байт)
Скорость скачивания: 47.10 Мбит/с (5.89 МБ/с)
```

## Единицы измерения

- Время — миллисекунды (мс).
- Объём — мегабайты (1 МБ = 1 000 000 байт) и байты.
- **Скорость — мегабиты в секунду (Мбит/с)**, как принято у провайдеров; для удобства рядом указан МБ/с (Мбит/с ÷ 8).

## Как считается

- Время каждого запроса — от отправки до получения последнего байта тела ответа (`process.hrtime`).
- Скорость = суммарный объём × 8 / суммарное время запросов.
- Кэширование отключено (`Cache-Control: no-cache`), но CDN всё равно может отдавать файл из своего кэша — на скорость скачивания это не влияет.
- Запросы идут строго последовательно. Таймаут одного запроса — 60 с. При ошибке (не 2xx, сеть, таймаут) скрипт завершается с кодом 1.
